# Roadmap

Features planned for upcoming releases. Items are not listed in priority order.

---

## Planned

- **Difftool and mergetool integrations** — hand diffs and merge conflicts off to
  your preferred external diff and merge tools.
- **Drag-and-drop merges** — drag one branch onto another in the graph to merge it.
- **File explorer and blame** — browse the repository's files at any commit and see who
  last changed each line.
- **OAuth** — sign in to hosting providers through the browser instead of managing
  credentials by hand.
- **LFS support** — work with Git Large File Storage repositories.

---

## Agentic coding

- **Review tours** — ordered stops through a branch inside Historia, each with a note and
  Prev / Next.
- **Agent annotations** — ephemeral notes from a coding agent on diff hunks.
- **Ask an agent about this** — hand a selected commit or hunk to an agent as a structured reference.
- **MCP server** — an MCP wrapper around `historia-cmdr`.
