# Roadmap

Features planned for upcoming releases. Items are not listed in priority order.

---

## Planned

- **Interactive rebase** — reorder, squash, fixup, edit, reword, and drop commits visually.
- **Diff viewer and conflict resolver integrations** — hand diffs and merge conflicts off to
  your preferred external diff and merge tools.
- **AI-generated commit messages** — draft a commit message from the staged changes.
- **Lightweight mode** — cap the number of commits displayed in favor of faster loads and a
  smaller memory footprint.
