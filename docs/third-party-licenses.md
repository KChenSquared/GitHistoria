## Material Symbols

The utility icon set in [`Historia.Core/Components/IconPaths.cs`](../Historia.Core/Components/IconPaths.cs)
(and its generated partial `IconPaths.Generated.cs`) is drawn from Google's
[Material Symbols](https://github.com/google/material-design-icons) icon library at pinned commit
`40a7a292a79d9394157e1ea24f83d52d5e17c556` (2026-09-11).

The glyph SVGs are vendored under [`assets/material-symbols/`](../assets/material-symbols/) and flattened
into C# path data by [`dev/vendor-material-symbols.ps1`](../dev/vendor-material-symbols.ps1).
Style parameters for vendored glyphs:
- Variant: **Outlined**
- Weight: **400** (`wght` 400)
- Grade: **0** (`GRAD` 0)
- Fill: **0** (`FILL` 0)
- Optical size: **24** (`opsz` 24)

Copyright Google LLC.
In compliance with Apache License 2.0 §4(b), the original SVG files were modified: each SVG path was
extracted, converted into embedded C# string path data on Material's 960-unit grid, and rendered at runtime
as a monochrome fill in `currentColor`.
Upstream carries no `NOTICE` file; §4(d) does not apply.
